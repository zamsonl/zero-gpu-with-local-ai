# Repository visuals

The PNGs show the actual browser and guided setup interfaces with example conversation data and an example project path. They were captured against isolated local mock services; they are interface previews, not a live inference benchmark or a real-account startup proof. No GPU was launched for these captures.

`hero.svg` and `how-it-works.svg` are static, self-contained project graphics. The product mark uses the existing bundled asset, rendered in black. Images contain no browser address bar, live service URL, user account, credential or private conversation.

When replacing captures, use disposable example data and leave the token entry empty. Review every image visually before publishing. Keep these images and the source ZIP synchronized with the README.

`quick-start.png` shows the restored standalone chat app. Other chat/setup PNGs show the optional advanced workspace. These are different entry paths; the README labels their feature differences. All conversations and model readouts in documentation captures use local fixtures, not a real inference benchmark.
