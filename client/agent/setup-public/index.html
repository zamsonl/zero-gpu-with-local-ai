    Troubleshooting & faster startup

    Launch limit reached? Check your active Kaggle notebooks first. To replace a stale token or use a different account, choose Forget saved token, enter the new token, then retry. Replacing a token for the same account does not reset its four-minute cooldown, daily launch limit or GPU quota.

    Check your Kaggle notebooks ↗

    Waiting for GPUs? The queue belongs to Kaggle. We check its reported status and keep a single session; repeated starts can make limits worse. Cancel setup before changing accounts.

    Can files on my PC speed this up? A cloud GPU cannot read a local model folder directly. Uploading the same weights each time is usually slower. A compatible private Kaggle dataset cache can skip downloads after GPUs are assigned; it cannot shorten the queue. Setup creates a private model/runtime Dataset in your own account using one reusable CPU builder. Default Qwen and supported custom Hugging Face GGUFs each keep their own pinned cache. Later launches reuse ready caches. The first build takes longer and needs enough private Dataset storage.
