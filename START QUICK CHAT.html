Zero GPU with Local AI · Quick Start

Run a notebook.
Open the chat.

Your cloud GPU runs Qwen. The chat app is already included. You do not need to create a website or install the model on this computer.

Caution: Quick Start has no compaction, no model/runtime caching, and no local coding agent. Want these features? Use Advanced Setup with DOWNLOAD ME.zip.

STEP 1

Open your notebook

Sign in with your own Kaggle account. The button opens the notebook import page.

Open notebook in Kaggle ↗
The import button did not work

In Kaggle, choose Create → New Notebook → File → Import Notebook, then upload notebooks/kaggle.ipynb from this folder.

STEP 2

Choose the GPU, then Run All

In Settings, select GPU T4 x2 and turn Internet on. Keep the notebook private.

Select Run All. Leave the settings cell unchanged for your first run. Wait for READY; downloads and model loading take time.

STEP 3

Click “Open the chat”

Use the private link printed in the notebook. The supplied chat page connects automatically.

If that page cannot load, open the included app below and paste the whole notebook link into its connection box.

Open included chat app

Keep the link private. It contains your session's connection key. You do not need a Kaggle API token for Quick Start.

Finished chatting?

Choose ⋯ → Shut the server down in the chat. Then check Kaggle and stop the notebook session to end its GPU allocation.

Chats stay in this browser. Use Settings → Your chats → Export all for a backup.

Use Colab instead

Open the Colab notebook, select T4 GPU under Runtime → Change runtime type, then Run all and keep its tab open. Check Colab's rules: free managed runtimes restrict primarily using a web UI.

Your account · your GPU allowance. Quick Start downloads model files again on fresh sessions. Read START HERE.md for troubleshooting.
