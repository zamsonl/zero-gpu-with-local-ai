# Advanced Setup — DOWNLOAD ME.zip

This is the complete source bundle for the advanced workspace.

**Just want to try chatting?** Download **Quick Start.zip** from the repository and open its **START HERE.html**. You do not need to deploy a website for Quick Start.

For compaction, model/runtime caching and the local OpenCode coding agent, follow **docs/SETUP.md** in this folder, or the online [Advanced Setup guide](https://github.com/zamsonl/zero-gpu-with-local-ai/blob/main/docs/SETUP.md).

1. Create your own Cloudflare resources and workspace key using section 1.
2. Deploy/configure your Worker using section 2.
3. Use `notebooks/advanced/` for a manually started advanced model notebook, or use the configured website controls.
4. For local coding, download the configured helper from `/agent/` on your own deployment and open `Start Qwen OpenCode.cmd`. Follow section 4 for the project picker, your own Kaggle token, private cache and browser tools.

The source helper is a template. It is not connected to the maintainer's service. Keep your keys and notebook outputs private. Model weights are not included in this ZIP.
