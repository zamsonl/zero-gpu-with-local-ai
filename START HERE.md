# Start here

This is a self-hosting source template, not a connection to the author's website.

1. Read `README.md` and `docs/SETUP.md`.
2. Create your own Cloudflare resources and key, deploy the Worker, configure your own relay URL, rebuild downloads and deploy again.
3. Website model notebooks are in `notebooks/`; always use your own URL/key and keep notebooks private.
4. Download the configured local-agent ZIP from your own deployed `/agent/` page. First setup creates a private per-account cache on CPU, then starts your GPU notebook.

Public ZIP templates have a blank endpoint. Do not paste a Kaggle token into an unconfigured package or a hosted chat prompt. Keep your private Dataset if you want model/runtime reuse.
